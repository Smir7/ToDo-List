# ToDo-List API

Это простой API для управления задачами (ToDo-List), написанный на Go с использованием фреймворка Fiber. API поддерживает основные операции CRUD (создание, чтение, обновление и удаление) для задач.
## Установка

1. Убедитесь, что у Вас установлен Go (версии 1.16 или выше).
2. Клонируйте репозиторий:

   ```bash
   git clone <URL_TO_YOUR_REPOSITORY>
   cd ToDo-List
   

 3. Установите зависимости:
    ```bash
    go mod tidy

 4. Создайте файл .env в корне проекта и добавьте следующие настройки:
    ```bash
    PORT=8080

### Запуск приложения
Для запуска приложения выполните следующую команду:

    ```bash
    go run cmd/main.go
Сервер будет запущен на порту, указанном в файле .env (по умолчанию 8080).

### Эндпоинты API
 Создать новую задачу
    * POST /tasks
    *Тело запроса:

    ```Json
    {
    "title": "Заголовок задачи",
    "description": "Описание задачи",
    "status": "новая"
    }   
* Ответ:
    - 201 Created: Созданная задача
    - 400 Bad Request: Неверный ввод

### Получить список всех задач
* GET /tasks
  * Ответ:
   - 200 OK: Список всех задач
  
  Получить задачу по ID
  * GET /tasks/:id
  * Ответ:
   - 200 OK: Задача
   - 404 Not Found: Задача не найдена

  Обновить задачу
  * PUT /tasks/:id
  * Тело запроса:

  ```Json
  {
  "title": "Обновленный заголовок",
  "description": "Обновленное описание",
  "status": "выполнена"
  }
* Ответ:
    - 200 OK: Обновленная задача
    - 400 Bad Request: Неверный ввод
    - 404 Not Found: Задача не найдена

  Удалить задачу
  * DELETE /tasks/:id
  * Ответ:
    - 204 No Content: Задача успешно удалена
    - 404 Not Found: Задача не найдена
  
### Тестирование API
  Вы можете протестировать API с помощью утилиты curl. Примеры запросов:

Создание задачи

    ```Bash
    curl -X POST http://localhost:8080/tasks -H "Content-Type: application/json" -d '{"title": "Заголовок задачи", "description": "Описание задачи", "status": "новая"}'

Получение всех задач

    ```Bash
    curl -X GET http://localhost:8080/tasks

Получение задачи по ID

    ```Bash
    curl -X GET http://localhost:8080/tasks/1

Обновление задачи

    ```Bash
    curl -X PUT http://localhost:8080/tasks/1 -H "Content-Type: application/json" -d '{"title": "Обновленный заголовок", "description": "Обновленное описание", "status": "выполнена"}'

Удаление задачи

    ```Bash
    curl -X DELETE http://localhost:8080/tasks/1
